# TCP-сервер точного времени

## Описание
Консольное приложение для создания TCP-сервера, обработки входящих сетевых подключений и вывода текущего системного времени.

## Автор
**Набиев Ислам**

## 🛠️ Технологии
- .NET 10.0
- C#
- System.Net.Sockets

## Использование
```bash
dotnet run
```
